Color

Use the semantic tokens in components. They resolve to the primitive ramps and flip between light and dark. The swatches below show the value for the current theme.

Typography

Early Sans Variable on the web (Arial while it loads), SF Pro on iOS and Roboto on Android. On the web only Display, H1 and H2 step down below 640px. Use the Platform toggle to see the native tiers.

Space, radius, size

Spacing runs on a 4px base. Radius is set by role. Interactive heights come from one ladder, so a control never sets its own height.

Layout

Two breakpoints, 640px and 1024px. Content caps at 1200px and running text at 588px. Native screens drop the column grid and use the platform margin.

Iconography

24px glyphs on a 2px live area, drawn in currentColor. Use ads-icon--sm for 16px. Select an icon to copy its markup.

Logos

The Travelmark in horizontal and vertical lockups. It takes currentColor, so it reads Primary Blue on light surfaces and white on inverse ones. Keep clear space and never stretch it.

Modal

One decision or a short piece of information. Secondary action first, primary last. Under 640px the buttons stack with the primary on top.

Change your return date?

Date Picker

Two panes for ranges on wide screens, one pane below 640px. Days are 36px cells.

App navigation

Tab bars follow Apple's iOS & iPadOS 27 kit: a floating Liquid Glass capsule at the bottom on iPhone and a glass bar centered at the top on iPad. Sizes, type and states match the kit; the selected tint is ADS brand blue. The top bar with the logo and booking search comes from the NextGen Mobile App file.
