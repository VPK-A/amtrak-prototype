# Claude API + MCP for the Amtrak prototype

This local stdio MCP server adds an `ask_claude` tool to Claude Code. The tool sends prompts to the Anthropic Messages API using the server-side TypeScript SDK. The API key stays in a local environment file and is never bundled into the Vite app or committed.

## Setup

Requirements: Node.js 20 or newer, npm, Claude Code, and an Anthropic API key with API access enabled.

From the repository root:

```sh
cd mcp
npm install
cp .env.example .env
```

Edit `mcp/.env` and set `ANTHROPIC_API_KEY` and `CLAUDE_MODEL`. Set the model to an API model identifier available to your Anthropic account. Keep `.env` private; it is ignored by Git.

Then start Claude Code from the repository root. The root `.mcp.json` registers this server automatically. In Claude Code, run `/mcp` and confirm `amtrak-claude-api` is connected. Ask Claude to use `ask_claude` to send a prompt to the API.

## Run the server manually

```sh
cd mcp
npm start
```

It waits for an MCP client on stdio. This command is not an interactive chat interface.

## Notes

- This is an optional developer tool; it does not change the browser prototype or its build.
- The Anthropic API key is used only by the local MCP process. Never put it in `src/`, `VITE_*` variables, or any client-side code.
- The MCP server SDK requires Node.js 20+, while the existing Vite app can still use its documented Node.js 18+ requirement.
- `mcp/package-lock.json` is generated by `npm install` so the installed dependencies can be locked locally.
